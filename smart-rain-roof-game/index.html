    Code the Arduino

    Change the two highlighted numbers, upload, and learn from the physical result.

    smart_roof.inoLIVE 
    #include <Servo.h>
const int RAIN_PIN = 7; const int SERVO_PIN = 9;
Servo awning;
void setup() { pinMode(RAIN_PIN, INPUT); awning.attach(SERVO_PIN); }
void loop() {
  if (digitalRead(RAIN_PIN) == HIGH) { // rain!
    awning.write(30°); // angle
    delay(1500); // wait ms
  } else { awning.write(0); }
}

    Mission: find an angle that covers every shirt and a delay that reacts before the washing gets wet.
